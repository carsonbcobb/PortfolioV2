**By Carson Cobb. Data collected November 16 and 17, 2026.**

Most CRO checklists are a list of best practices with no sense of which ones matter. This one shows how many established Shopify brands actually do each thing. The checks most stores fail are where a store can pull ahead fastest.

## Product page buy box

| Check | Pass rate |
| --- | --- |
| First product image not lazy loaded | 66% |
| Quantity selector | 63% |
| Product recommendations | 51% |
| Image marked high priority | 43% |
| Variant buttons, not dropdowns (pages with choices) | 42% |
| Sticky add to cart | 37% |
| Guarantee or free returns stated | 34% |
| Delivery estimate shown | 11% |

## Product page content

| Check | Pass rate |
| --- | --- |
| Mentions shipping | 93% |
| Says what it's made of | 75% |
| Says who it's for | 38% |
| Explains how to use it | 31% |
| Mentions testing or certification | 30% |
| Compares options | 25% |
| Video | 24% |

## Collections and search

| Check | Pass rate |
| --- | --- |
| Search still finds products with a missing letter | 90% |
| Search returns something for "gift" | 89% |
| Search still finds products with swapped letters | 73% |
| Sorting on collections | 63% |
| Filters on collections | 62% |
| Collection description | 49% |

## Homepage and accessibility

| Check | Pass rate |
| --- | --- |
| Zoom allowed on mobile | 93% |
| Skip to content link | 83% |
| Exactly one H1 | 54% |
| No links without a name | 46% |
| Passes all five basic accessibility checks | 18% |

## Testing and measurement

| Check | Pass rate |
| --- | --- |
| Session recording tool | 41% |
| Attribution tool | 40% |
| A/B testing tool | 33% |

## Decision pages

| Check | Pass rate |
| --- | --- |
| Reviews page | 49% |
| Product quiz or finder | 40% |
| Science or testing page | 24% |
| Comparison page | 11% |

## Where to start

Work from the bottom of each table up, on your top selling products first:

1. **The buy box.** Delivery estimate, guarantee line, buttons for variants, fast first image. ([Buy box](/reports/shopify-product-page-buy-box-2026), [variant pickers](/reports/shopify-variant-picker-buttons-vs-dropdowns-2026), [image loading](/reports/shopify-image-loading-speed-2026))
2. **Product page content.** Who it's for, how to use it, how it compares. ([What AI named brands have in common](/reports/what-ai-named-shopify-brands-have-in-common-2026))
3. **Navigation.** Filters by need, sorting, and search that survives typos. ([Filters](/reports/shopify-collection-filters-sorting-2026), [site search](/reports/shopify-site-search-typos-2026))
4. **Accessibility basics.** Labels, alt attributes, zoom. ([Accessibility statistics](/reports/shopify-accessibility-statistics-2026))
5. **Then test.** A checklist gets you to average. Testing tells you what works for your shoppers. ([A/B testing on Shopify](/reports/shopify-ab-testing-tools-2026))

The AI side of the same work is in the [AI search checklist for Shopify](/reports/ai-search-checklist-shopify-2026).

## How this was done

- **Stores:** Shopify brand stores in six product areas from my dataset of 620, client stores excluded. Most checks come from 599 stores scanned November 17, 2026. Product page content, testing tools and measurement tools come from 617 stores scanned November 16 and 17, 2026.
- **Pages:** each store's homepage, the product page of the first product in its public feed, its all products collection, its predictive search and its page sitemap, read as first sent by the server.
- **Limits:** checks are automated and keyword or code based. They show whether something is present, not how well it works.

No store or brand is named in this report.
